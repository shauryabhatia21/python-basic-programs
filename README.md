# Python Basic Programs

A collection of 26 foundational Python programs and algorithm solvers.

## 📌 Programs Covered

- **Number Systems**: Binary to Decimal, Decimal to Binary
- **Math & Arithmetic**: Factorials, Armstrong numbers, Palindromes, Fibonacci series, Prime number checks, GCD & LCM
- **Patterns**: Star patterns, pyramid printing, number grids
- **Control Flow**: Conditional evaluation, loops (`for` and `while`)

## 🚀 Usage
```bash
python filename.py
```
